# 《书籍写作》

## 从读者承诺到可信、可读、可出版的非虚构书

**读者承诺**：帮助准备写实用型、解释型或商业型非虚构书的作者，从一个重要读者问题开始，设计书的承诺、研究来源、全书结构、章节、初稿、修订和读者测试；不承诺畅销或出版合同。
